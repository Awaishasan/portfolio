# Awais Hassan — Portfolio

Personal portfolio website for Awais Hassan — Flutter & Mobile App Developer,
AWS Certified Cloud Practitioner, Computer Science undergraduate at COMSATS
University Islamabad, Sahiwal Campus.

Built with Anime.js animations and a Three.js animated hero background.
Single static file (`index.html`), no build step needed.

## View it

Open `index.html` in a browser, or deploy it for free on Vercel:

1. Import this repository at [vercel.com](https://vercel.com) (Add New → Project).
2. Click **Deploy** — no build settings needed.
3. Share the live link, e.g. `awais-portfolio.vercel.app`.

## Add a project

Edit the `PROJECTS` array near the top of the `<script>` in `index.html`,
or use the "Add a project" form on the site (projects added through the
form stay in that visitor's browser only).
